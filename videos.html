Why did I create this page that looks so much like YouTube?

I created this page, which looks very much like YouTube, because before when I opened up YouTube to publish my videos, I kept getting overwhelmed with all the other stuff there. I kept getting distracted by other videos, disheartened by comparing myself to other creators, looking at my statistics, seeing different ways I can customise my page, etc. So I created this, a place where I do everything that needs to be done – like the thumbnail, the title and testing what that looks like – before I go to publish it.

I just want to create what feels true to me, and share it calmly. All unnecessary faff removed.

If you feel like this process could be helpful for you too, please feel free to copy! I made it with Claude Code. I’d be more than happy if I can help you also have a more calm experience sharing what you create!
